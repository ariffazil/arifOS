## Compression

Each organ preserves something different:

- FRAME preserves Reality
- arifFLOW preserves Experience flow
- CHRON preserves Consequence through time
- HERMES preserves Meaning
- AAA preserves Choice
- arifOS preserves Legitimacy
- A-FORGE preserves Action

## Organ ↔ CHRON Boundaries

### arifOS ↔ CHRON
- arifOS = law (governs transitions, authority, legal moves)
- CHRON = history (what happened, when, what was believed, what was corrected)

### arifFLOW ↔ CHRON (critical boundary)
- arifFLOW publishes → CHRON interprets
- arifFLOW = time as sequence
- CHRON = time as meaning
- arifFLOW already has: receipts, cycles, telemetry, events
- CHRON needs: episodes, predictions, verification, learning

### FRAME ↔ CHRON
- FRAME witnesses → CHRON narrates
- FRAME must be outside CHRON's authority
- FRAME must be able to say "CHRON is wrong" without CHRON's permission

### HERMES ↔ CHRON
- CHRON = chronology (Event A before Event B)
- HERMES = semantics (why it matters, how to interpret)

### WELL ↔ CHRON
- WELL owns vitality evidence (sleep, energy, fatigue, body events)
- CHRON owns temporal lineage (what happened, when, outcome, trend)

### WEALTH ↔ CHRON
- WEALTH owns prices, assets, financial flows
- CHRON owns expectation vs outcome through time
- Example: Prediction "Fuel prices rise by Q4" → verify_at 2026-12-31 → Outcome: False

### GEOX ↔ CHRON
- GEOX owns places, projects, wells, geospatial reality
- CHRON owns episodes, timelines, changes, consequences
- Example: Bekok Deep-1 belongs to GEOX; "What was believed before Bekok?" belongs to CHRON

### AAA ↔ CHRON
- AAA is the primary consumer of CHRON
- AAA asks: "What path should we take?"
- CHRON provides: historical consequences of previous paths
- AAA chooses, CHRON provides temporal evidence

### A-FORGE ↔ CHRON
- A-FORGE creates experience (every execution → action → outcome → episode)
- CHRON metabolizes experience
- A-FORGE creates scars, CHRON remembers which scars mattered
