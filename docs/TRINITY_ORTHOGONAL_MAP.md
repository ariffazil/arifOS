- Law: F1–F13 floors
- Verdict: SEAL / HOLD / VOID

**arifOS asks:** "Is this action lawful, reversible, evidenced, and aligned?"

### Axis 2 — AAA / A2A: Who should handle this, and what can Arif see?

- Registry: Which agents exist
- Routing: Which organ receives the task
- Visibility: What Arif sees
- Approval queue: What needs F13 / human review
- Failure mode: Cockpit pretending to be judge or executor

**AAA asks:** "Where does this task go, who owns it, and what must Arif see?"

### Axis 3 — A-FORGE: How do we safely do it?

- Build: Compile, package, test
- Mutation: Edit files, deploy services, run shell/git/docker/browser
- Rehearsal: Dry run before reality change
- Supply chain: Scan, sign, prove, audit
- Failure mode: Mutation without authorization, irreversible damage, secret leak

**A-FORGE asks:** "Given valid authorization, how do we execute safely, reversibly, and audibly?"
