# GENESIS 030 — REALITY ENGINEERING AXIOMS
Status: F13_RATIFIED_CHAT 2026-10-15 — sovereign "1 2 3" (Option C ratified; source: reality-graph disambiguation session + independent verification pass, external refs arXiv:2608.21156 + realitygraph.dev verified F2)

## Axiom R1 — Definitions (canonical compression)
> Reality engineering is the construction of systems in which representations remain traceable to evidence, decisions remain bounded by authority, actions remain tied to receipts, and consequences can revise future behavior.
> A reality graph is the versioned structure connecting entities, claims, evidence, contradictions, authority, actions, and witnessed consequences without confusing any one of them for reality itself.

Context engineering manages what an agent can SEE. Reality engineering governs what an agent may treat as TRUE, AUTHORIZED, and CONSEQUENTIAL.

## Axiom R2 — Three planes (inseparable)
- Reality Plane — what is witnessed (observation ≠ interpretation).
- Authority Plane — who may commit (capability ≠ authority; pre-execution gate, not post-hoc audit).
- Consequence Plane — what changed (PRODUCED ≠ SENT ≠ DELIVERED ≠ OBSERVED).
Without reality → hallucination. Without authority → overreach. Without consequence → proposal ≡ result (collapse).

## Axiom R3 — Paradigm boundaries (no label collapse)
Context Eng (what to show) · Memory Eng (what to retain; MAP proposes) · Graph Eng (how work coordinates) · Knowledge Graph (how entities link semantically) · Reality Eng (what is provably true, authorized, witnessed). Each answers a different question; none substitutes another.

## Axiom R4 — Hardening laws
1. CLOSED LOOP: every [Observed Consequence] carries a GENERATES_WITNESS edge back to the Reality Plane. Receipts file to the ledger; NEW OBSERVATIONS update the territory.
2. PRE-COMMIT INTERCEPTION: [Authorized Decision] → [Action] is a kernel gate (ACT/sct envelope) BEFORE execution — never only post-hoc diff detection.
3. EPISTEMIC DECAY: VALID_DURING expiry without fresh OBSERVED_BY demotes node status VERIFIED/PROVISIONAL → STALE/UNKNOWN. Stale memory must never masquerade as present reality.

## Boundary
Representation remains smaller than reality. The reality graph is a governed witness structure, not reality itself. Retrieval ≠ verification ≠ authorization ≠ consequence.
