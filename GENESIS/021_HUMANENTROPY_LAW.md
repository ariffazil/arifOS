## The Core Law

An MCP App or agentic system is acceptable **only if** it:

1. **Decreases uncertainty**
2. **Increases human agency**
3. **Preserves reversibility**

## The 13 Specifications

### F1 — Truth Preservation

> The system must never convert uncertainty into certainty.

Every output carries: source, epistemic_class (FACT|INTERPRETATION|HYPOTHESIS), uncertainty.

### F2 — Evidence Conservation

> Every important conclusion must preserve its causal chain.

```
Evidence → AI reasoning → human judgment
```

Never: `AI answer → human belief`

### F3 — Human Agency Preservation

> AI increases capability. It never replaces sovereignty.

Human holds: final_decision. Agent holds: recommendation. Authority is bounded.

### F4 — Reversibility First

> Every action classified by reversibility.

FULL (read) → PARTIAL (write) → NONE (seal). Irreversible requires evidence floor + human approval + audit trail.

### F5 — Entropy Budget

> Every cycle measures whether it adds or removes disorder.

If agent creates more dashboards/alerts/interpretations/dependencies without reducing uncertainty: **STOP.**

### F6 — Provenance Sovereignty

> Every important object needs identity.

Minimum: session_id, actor_id, trace_id, source, timestamp, version. A result without provenance is informational pollution.

### F7 — No Hidden Intelligence

> Expose what is known and what is not.

Show: confidence, evidence count, unknowns, next action. Never: "world-class reservoir detected."

### F8 — Capability Boundaries

> Tools declare their authority. They do not exceed it.

observe | reason | act — each declared. A geology tool does not become financial authority.

### F9 — Agent Identity Continuity

> Three identities never mix: MCP session, governance session, human actor.

Never: `anonymous tool call = trusted decision`

### F10 — Anti-Hallucination Architecture

> Structural prevention, not model behavior reliance.

```
Tool result → Schema → Evidence → Physics → Governance → Human
```

The model is not the final safety layer.

### F11 — Cognitive Load Reduction

> Good tools reduce human mental entropy.

Bad: 100 charts, 50 warnings, 20 opinions.
Good: 3 facts, 2 unknowns, 1 reversible next step.

### F12 — Ecosystem Interoperability

> One capability, many hosts.

No vendor lock-in. GEOX serves ChatGPT, Claude, custom workbenches, government systems.

### F13 — Emergent Agent Constitutional Ceiling

> Capability grows inside boundaries.

May increase: knowledge, speed, simulation, coordination, pattern discovery.
Must not increase: unaccountable power, opacity, irreversible action, human dependency, centralized control.
