# Proof Epoch

This directory separates implementation evidence from acceptance authority.

- `acceptance-manifest.json` locks the mandatory denominator before execution.
- `proof-epoch-result.json` is generated by `scripts/run_proof_epoch.py`; the builder cannot reclassify failures.
- `accepted-risk-register.json` records risk decisions separately from physical chain validity.
- A generated PASS is test evidence only. It is not an independent VAULT seal.

Run: `python scripts/run_proof_epoch.py`
