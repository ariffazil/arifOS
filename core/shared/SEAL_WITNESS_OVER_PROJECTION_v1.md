## 3. THE HOSTILE AUDIT TEST

A true pattern gets stronger when reality pushes back. A projection collapses.
Every relational theory must face the **Hostile Audit**:

1.  **Bring the Rupture:** Where did we fail?
2.  **Bring the Repair:** How did we fix it?
3.  **Bring the Counterexample:** What data contradicts my favorite theory?
4.  **Bring the Pain:** What evidence hurts my ego but helps the truth?

If a connection survives this audit, it is **Witnessed Reality**.
If it fails, it was **Projection**.
